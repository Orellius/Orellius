## Repositories

**Live**

- **[glyphcast](https://glyphcast.tv)** — Typography-only video codec. Every frame is a grid of Unicode glyphs, not pixels: GPU-rendered in a single draw call, on a wire a terminal can decode and a language model can read. Open core: [glyphcast-core](https://github.com/Orellius/glyphcast-core), Apache-2.0.
  `Rust / WebGL2 / Bun`

- **[azaka](https://azaka.orellius.ai)** — Red Alert (Tzeva Adom) live map off the official oref feed, served through an egress relay that solves the Israeli-IP geoblock. Threat zones on a map, instead of a list of place names you have to parse.
  `React / MapLibre / Bun`

- **[responsive-viewer](https://github.com/Orellius/responsive-viewer)** — Preview the page you are on at any device resolution, in place. 168 device presets, no resolution lock, no paywall.
  `MV3 / TypeScript`

- **[opendisplay](https://github.com/Orellius/opendisplay)** — Unlocks the HiDPI modes macOS hides on sub-4K external panels. No kernel extension.
  `Swift / AppKit`

**Building**

- **roleplay-fw** — Modular roleplay framework running on a live FiveM server. `Lua 5.4 / OneSync`
