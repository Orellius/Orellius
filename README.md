# Orel Ohayon

I build desktop apps, agentic dev tools, and a FiveM roleplay framework. Israel-based. Mostly Rust + Tauri 2 for desktop, TypeScript + Next.js 16 + Bun for web, and Lua on FXServer for Grand Theft Auto FiveM Multiplayer game servers.

Public on this account: a few prototypes I haven't archived  ([Vorel](https://github.com/Orellius/Vorel), [Orelium](https://github.com/Orellius/Orelium) ([rubato](https://github.com/Orellius/rubato), [isq](https://github.com/Orellius/isq), [januas-ade](https://github.com/Orellius/januas-ade)), and older work in [jarvis-mcp](https://github.com/Orellius/jarvis-mcp) / [Telegram-Channel-Manager](https://github.com/Orellius/Telegram-Channel-Manager) / [orelion-x-v1](https://github.com/Orellius/orelion-x-v1) / [januas-hooks-v1](https://github.com/Orellius/januas-hooks-v1).

The Hebrew-first products, the FiveM framework, and the agentic OS layer over Claude Code stay private until they're worth shipping.
